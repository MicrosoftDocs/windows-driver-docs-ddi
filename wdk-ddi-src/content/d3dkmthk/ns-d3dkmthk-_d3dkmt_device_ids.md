# D3DKMT_DEVICE_IDS structure

## -description

The **D3DKMT_DEVICE_IDS** structure contains ID information for a graphics device.

### -field VendorID

Vendor ID.

### -field DeviceID

Device ID.

### -field SubVendorID

Subvendor ID.

### -field SubSystemID

Subsystem ID.

### -field RevisionID

Revision ID.

### -field BusType

Bus type.
